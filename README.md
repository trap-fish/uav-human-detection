## UAV Human Detection
This repo was the code base for my MSc Internet of Things thesis.

### About this project
This repo was primarily used for research purposes and thus there remain some rough scripts and irrelevant files which will be archived later. Please refer to the repository's wiki for more information on the approach taken.
A modified version of this was published in Proceedings of the 32nd International Society of Transdisciplinary Engineering (ISTE) Global Conference and can be found [here](https://ebooks.iospress.nl/volumearticle/75473). This differs from the original thesis report as greater emphasis on the application as opposed to technical approach was given.

### Reproduction
This was a solo project by nature (as it was my thesis) in terms of the technical work, thus did not document deployment, reproduction etc, though planning to get around to this before archiving this repository in 2026. In the meantime please refer to the wiki

### Deployment
If you wish to use these models, the Pytorch, ONNX, openVINO and HAR models will all be make available as soon as I can make some space in my cloud storage!
